# LIGHTBOUND Rolls — fan database

A fan-made database for **[LIGHTBOUND](https://cobalttornado1.itch.io/lightbound)** by William Worth, inspired by light.gg.

**Live site:** https://kapitockay.github.io/lightbound-db/

- every weapon type with its full perk pool (same rules as the game: element, frame, rarity)
- all god rolls and which weapons can roll them
- exotics (frame, exotic perk, random trait pool), armor sets, mods
- collection: skiffs, ships, emblems, transmats, Wisp shells, items, lore
- damage table for every frame
- English, Russian and German
